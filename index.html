如何發放給學生使用？

💡 方案 A：直接提供單一 HTML 檔案（最推薦）

您可以將此 `.html` 檔案直接上載至學校的 **Google Classroom、Teams 或校園 intranet**，學生下載後用瀏覽器雙擊即可直接開啟運作！

🌐 方案 B：免費部署網頁連結（可供全校開啟）

只需將此單一 HTML 檔上載至 **GitHub Pages**、**Netlify** 或 **Vercel** 等免費平台，即可獲取專屬網頁網址，直接分享 QR Code 俾小學生掃描使用。

🤖 關於 AI 對話 API KEY 設定

此網頁預設調用 Gemini Flash API。學校若有提供 API Key，可在網頁代碼中嵌入；若未輸入，系統亦內建智能備用對話回應，確保課堂流暢不受影響！
